# Harmonica Studio

个人口琴乐谱管理、写谱与练习 WebUI。当前处于需求设计阶段，尚未实现应用。

## 已确认方向

- 主要使用新 WebUI 编辑乐谱，管理现有本地收藏。
- 数字 1～7 表示音阶，不表示口琴孔位；默认 C，可选 A。
- `[]` 表示高音，`()` 表示低音，`#` 表示推键。
- 大数字提示长音，小数字提示短音；按句分行。
- Shift + 数字输入高音，Ctrl + 数字输入低音，Alt 添加推键标记；快捷键可自定义。
- Z / C 调整光标后音符的大小和音长，支持细调；不采用按住计时录入音长。
- 支持播放试听，帮助听乐写谱和练习；具体音色待验证。
- 考虑未来由 Luna 转谱后导入、人工校对。
- 保持简单，不做复杂的音乐制作工作站。

## 待确认

- Z / C 的方向、步长、精调方式及字号映射。
- 换行快捷键（用户原文“ta”，尚未确认是否 Tab）。

- 部署方式、设备支持、练习台和管理功能的具体范围。
