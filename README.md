# Harmonica Studio

个人口琴乐谱管理、写谱与练习 WebUI。第一版支持真实乐谱库、数字谱编辑、本地保存和口琴采样播放。

## 启动与验证

需要 Node.js 22+。首次安装依赖后，音色与应用均由本地服务提供，日常使用不依赖外网。

```powershell
cd D:\Harmonica
npm ci
npm start
# 另一个终端运行测试
npm test
npm run test:e2e
```

打开 http://127.0.0.1:4317 使用写谱台。也可双击 `start.cmd` 启动；保持启动窗口开启，Ctrl+C 停止服务。
`npm start` 自动构建前端。浏览器验收测试默认使用已安装的 Chrome，配置见 `playwright.config.mjs`。
原谱只读，新谱保存在本机 `data/`，不会提交 Git。
接口、环境变量、JSON 转谱格式与当前限制见 [API 文档](docs/API.md)。

旧版 [视觉提案](docs/design/harmonica-studio.html) 仅为设计档案，实际应用请打开本地服务。
口琴音色的来源与长音验证见 [音色说明](docs/SOUNDFONTS.md)。

## 第一版使用

1. 点击「新建乐谱」，点击谱面后输入 1–7；0 是休止。
2. Shift + 数字为高音，Ctrl + 数字为低音，Alt + 数字加推键；支持叠加高低音与推键。
3. 点击一个音符，用 Z 延长、C 缩短，按住 Shift 或勾选「细调」小幅调整。字号跟随长短，范围有限，不会无限放大或缩小。
4. Enter 开始下一句，空格仅作视觉分组；休止请输入 0。方向键移动，Backspace / Delete 删除。Ctrl+A 全选、Shift+点击多选，Ctrl+C / V 复制粘贴；应用内复制保留音长。
5. 「复制本句」保留这一句的音高与音长；Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做。
6. 点击「播放」试听，可暂停、继续、停止、循环整首或当前句；可切换口琴 / 合成音、音量、BPM 与 C / A 调。
7. 点击「保存乐谱」或 Ctrl+S 写入 `data/`。未保存的当前草稿在同一浏览器恢复；切换乐谱前请保存。保存会留一份 `.bak`，删除会移到 `data/trash/`。
8. 左侧可搜索、按收藏 / 练习状态筛选；分类、收藏与练习状态随乐谱保存。
9. 「导入数字谱 / JSON」支持粘贴和选择文件；模型转谱使用 [API 文档](docs/API.md) 的 JSON 格式，可保留准确音长。导入会创建新 ID，不覆盖原谱；导出也保留全部时值。
10. 「练习」收起编辑工具；「快捷键与外观」可改按键、谱面大小与配色。音符特效可独立关闭，关闭后仍保留当前音符高亮。

原有 Markdown 收藏可在主区域阅读，新建文字草稿需手动校对；没有右侧原谱对照面板。当前不会自动识图、猜测字号时值或调用模型转谱。手机可阅读与播放，快捷输入主要面向电脑实体键盘。

## 已确认方向

- 主要使用新 WebUI 编辑乐谱，管理现有本地收藏。
- 数字 1～7 表示音阶，不表示口琴孔位；默认 C，可选 A。
- `[]` 表示高音，`()` 表示低音，`#` 表示推键。
- 大数字提示长音，小数字提示短音；按句分行。
- Shift + 数字输入高音，Ctrl + 数字输入低音，Alt 添加推键标记；快捷键可自定义。
- Z / C 调整光标后音符的大小和音长，支持细调；不采用按住计时录入音长。
- 支持口琴采样和合成音播放试听，帮助听乐写谱和练习。
- 考虑未来由 Luna 转谱后导入、人工校对。
- 保持简单，不做复杂的音乐制作工作站。
- 前端以数字谱为中心，播放时带可关闭的跟随音符特效。
- 转谱子代理限定 Luna 或 GPT-6.1-sol medium；本轮未进行自动转谱。

## 当前约定与后续调整

- C / A 暂按整体移调；中音 1 分别是 C4 / A3，推键升半音。可在实际练习后调整基准。
- 音长范围 0.125–8，普通步长 0.125、细调 0.025，不限制为几种拍值。
- 默认 Enter 换行，可在设置中改为 Tab；换行不自动停顿，0 表示休止。
- 新谱采用独立 JSON，不写回旧 Markdown。具体格式见 API 文档。
- 当前只监听本机，不包含局域网、账号、多用户冲突合并或云端部署。

## 导入注意

已检查的收藏采用 Markdown 引用图片，图片可能位于乐谱根目录以外。
部分笔记包含 OCR 简谱与孔位转换草稿，存在括号错乱并丢失字号信息。
应保留原图对照，不将草稿视为准确的可播放乐谱；未经校对的节奏不能保证还原。

本仓库保存应用源码与设计资料。个人乐谱、图片、音频、数据库及本地配置不提交。
