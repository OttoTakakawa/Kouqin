# Harmonica Studio

个人口琴乐谱管理、写谱与练习 WebUI。第一版支持真实乐谱库、数字谱编辑、本地保存和口琴采样播放。

## 启动与验证

需要 Node.js 22+。首次安装依赖后，音色与应用均由本地服务提供，日常使用不依赖外网。

```powershell
cd D:\Harmonica
npm ci
npm start
# 另一个终端运行测试
npm test
npm run test:e2e
```

默认启动地址为 http://127.0.0.1:4317。当前开发机实际使用的新版服务为 http://127.0.0.1:4318，数据目录为 `data/rework-preview`，与默认目录不互通；重开现有曲库请按下方指定环境变量，避免误开空库。也可双击 `start.cmd` 启动默认实例。
`npm start` 自动构建前端。浏览器验收测试默认使用已安装的 Chrome，配置见 `playwright.config.mjs`。
原谱只读，新谱保存在本机 `data/`，不会提交 Git。
接口、环境变量、JSON 转谱格式与当前限制见 [API 文档](docs/API.md)。当前实现、数据归属、验证结果及接手注意事项见 [HANDOFF](docs/HANDOFF.md)。

已有4318曲库的启动方式（先确认该端口没有服务运行；不要重复启动或覆盖数据）：

```powershell
$env:PORT="4318"
$env:HARMONICA_DATA="D:\Harmonica\data\rework-preview"
npm start
```

旧版 [视觉提案](docs/design/harmonica-studio.html) 仅为设计档案，实际应用请打开本地服务。
口琴音色的来源与长音验证见 [音色说明](docs/SOUNDFONTS.md)。

## 第一版使用

1. 点击「新建乐谱」，点击谱面后输入 1–7；0 是休止。
2. Shift + 数字为高音，Ctrl + 数字为低音，Alt + 数字加推键；支持叠加高低音与推键。
3. 点击音符，用 Z / C 或 − / ＋ 调整时值；旁边可直接选择 `1/16、1/8、1/4、1/2、全音`。附点和完整时值表放在「更多 → 精确设置」。四分音符作为 1 拍。
   批量修改：点击第一个音，再 Shift+点击最后一个音；也可从「更多」选本句或在谱面 Ctrl+A 全选。直接选择分数音长会一起设置所选音符，整次操作可以一次撤销。
   段尾处理：「延长尾音」给选区最后一个有声音的数字增加指定时值，取消后恢复原音长；「段后留白」插入实际停顿，在谱面显示为灰色「停」，可调整或删除。循环终点后的留白会一并纳入循环。
4. 点击「换行」按钮或按 Enter 在光标处开始下一句，空格插入四分休止（1拍），存在选区时追加到选区后，保护原音符；0也可输入休止。旧分组空格显示为灰色「·」且不占拍，选中可设置时值转成休止；没有「不停」选项。点击音符或「停」后，Backspace / Delete 直接删除该符号并保留当前位置；方向键移动光标后，Backspace 删除前一个符号，Delete 删除后一个符号。点击行号选整行，拖动或 Shift+方向键选择片段，Ctrl+A 全选、Shift+点击多选。Ctrl+C / X / V 或编辑栏「复制 / 剪切 / 粘贴」操作剪贴板，保留音长、尾音、休止和换行。复制下一整行后，点击上一行的「行尾」再粘贴可追加；点击上一行行号再粘贴可替换整行。空剪贴板或非法文本不会覆盖原谱。
5. 「复制本句」保留这一句的音高与音长；Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做。
6. 点击一个音符定位，再点「播放」从该音起播；双击音符直接播放，跟随开启时播放中单击会跳转，暂停后点击重新定位。「从头播放」回到整首开头。可暂停、继续、停止，切换六种免费口琴采样 / 合成音、音量与 C / A 调。播放速度只有一个入口，预设和滑杆操作同一有效BPM，随每首乐谱分别保存。
   编辑模式默认将当前播放行居中。手动滚动后自动暂停跟随，可选择下面的音符编辑，不会被拉回或跳播；点击底栏「回到播放行」恢复跟随，也可点击「跟随播放」主动关闭。
   点击行号选中整句，再点同一行号从句首起播。播放栏「循环本行」在写谱和练习模式均可用；循环中编辑音长后继续播放。
   循环练习：展开底部「片段练习」，点击起始音后点「设 A」，点击结尾音后点「设 B」，自动启用 A–B 循环并包含结尾音；也可多选后点「选区设为循环」。写谱的选择范围与播放端点独立，切换写谱 / 练习不会丢失端点或编辑选区。点击 A/B 外的音符会退出片段播放，但保留端点供重新选择；整首和当前句也可循环。音色、音量与特效直接显示在底部播放栏。
7. 点击「保存乐谱」或 Ctrl+S 写入 `data/`。未保存的当前草稿在同一浏览器恢复；切换乐谱前请保存。保存会留一份 `.bak`，删除会移到 `data/trash/`。
8. 左上角 ☰ 可收起 / 展开整个乐谱列表，分类标题也可分别折叠；折叠状态会记住，搜索时展开匹配分类。左侧可搜索、按收藏 / 练习状态筛选；分类、收藏与练习状态随乐谱保存。
9. 「导入数字谱 / JSON」支持粘贴和选择文件；模型转谱使用 [API 文档](docs/API.md) 的 JSON 格式，可保留准确音长。导入会创建新 ID，不覆盖原谱；导出也保留全部时值。
10. 「练习」收起编辑工具；「快捷键与外观」可改按键、谱面大小与配色。音符特效可独立关闭，关闭后仍保留当前音符高亮。

原有 Markdown 收藏可在主区域阅读，新建文字草稿需手动校对；没有右侧原谱对照面板。当前不会自动识图、猜测字号时值或调用模型转谱。手机可阅读与播放，快捷输入主要面向电脑实体键盘。

## 已确认方向

- 主要使用新 WebUI 编辑乐谱，管理现有本地收藏。
- 数字 1～7 表示音阶，不表示口琴孔位；默认 C，可选 A。
- `[]` 表示高音，`()` 表示低音，`#` 表示推键。
- 大数字提示长音，小数字提示短音；按句分行。
- Shift + 数字输入高音，Ctrl + 数字输入低音，Alt 添加推键标记；快捷键可自定义。
- Z / C 按标准时值调整音符大小和音长，支持附点；不采用按住计时录入音长。
- 支持口琴采样和合成音播放试听，帮助听乐写谱和练习。
- 考虑未来由 Luna 转谱后导入、人工校对。
- 保持简单，不做复杂的音乐制作工作站。
- 前端以数字谱为中心，播放时带可关闭的跟随音符特效。
- 转谱子代理限定 Luna 或 GPT-6.1-sol medium；已有本机Luna转译资料，但个人曲库和校对中间文件不随代码提交。

## 当前约定与后续调整

- C / A 暂按整体移调；中音 1 分别是 C4 / A3，推键升半音。可在实际练习后调整基准。
- 常用音长为 0.125、0.25、0.5、1、2、4、8 拍，附点增加原时值的一半。导入的其他估计值保留并显示「自定音长」，手动调整时进入标准档，不自动改写整首谱。
- 底部「播放速度」统一BPM和旧倍率；舒缓60、适中90、轻快120、快速160预设与滑杆修改同一数值，保存后每曲独立记住。旧谱加载按 `bpm / durationScale` 保持实际快慢，手动调速后普通范围归一为bpm。音符长短和字号不随调速修改。实现约定见 [播放与音长](docs/DESIGN.md)。
- 默认 Enter 换行，可在设置中改为 Tab；换行不自动停顿，0 表示休止。
- 新谱采用独立 JSON，不写回旧 Markdown。具体格式见 API 文档。
- 当前只监听本机，不包含局域网、账号、多用户冲突合并或云端部署。

## 导入注意

已检查的收藏采用 Markdown 引用图片，图片可能位于乐谱根目录以外。
部分笔记包含 OCR 简谱与孔位转换草稿，存在括号错乱并丢失字号信息。
应保留原图对照，不将草稿视为准确的可播放乐谱；未经校对的节奏不能保证还原。

## 项目边界

本仓库保存应用源码、测试、设计资料与允许分发的公共音色采样及许可。个人乐谱、原图、私人录音、数据库及本地配置不提交。

免费音色：在「底部播放栏 → 音色」中切换 FluidR3、MusyngKite 与合成音；采样随应用本地提供，无需联网。音色许可与来源见 THIRD_PARTY_NOTICES.md。

其余免费口琴音色也已接入：GeneralUser GS、VCSL常规/柔和/颤音。编辑模式空格直接插入四分休止（1拍）；整行或多选时在选区后追加，不覆盖所选音符。旧谱分组点「·」仍不占拍，「不停」选项已移除。
