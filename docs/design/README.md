# 前端视觉提案

打开 [harmonica-studio.html](harmonica-studio.html) 查看可点击的静态原型。

## 已确认

- 保留左侧曲目库、主数字谱、底部播放条。
- 用户明确不要右侧原谱对照面板。
- 练习模式收起曲目列表，把空间留给数字谱。
- 音符特效可关闭。原型现在将开关保存在 localStorage，重新打开时恢复。
- 首次访问尊重系统减少动态效果偏好；关闭特效仍保留当前播放音符高亮。

## 未定稿

- 当前松绿色配色仅为试稿；用户认为配色尚不够好，不得标记为最终认可。
- 曲谱与曲目为布局示例；原型没有连接真实乐谱、音频播放和保存接口。
- 原型播放只模拟视觉跟随；音色调研见 [SOUNDFONTS.md](../SOUNDFONTS.md)。

## 原型可试操作

写谱 / 练习切换、选中音符、Z / C 或按钮调整音长、当前句 / 整首视觉播放、特效开关与搜索。
Z / C 仅在谱面获得焦点时生效。正式版的数字输入、快捷键配置与保存仍待实现。
