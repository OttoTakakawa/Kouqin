# 前端视觉提案

此目录保留早期静态提案。第一版实际应用使用 `public/` 源码，请运行 `npm start` 后打开 http://127.0.0.1:4317。

## 已确认

- 保留左侧曲目库、主数字谱、底部播放条。
- 用户明确不要右侧原谱对照面板。
- 练习模式收起曲目列表，把空间留给数字谱。
- 音符特效可关闭。原型现在将开关保存在 localStorage，重新打开时恢复。
- 首次访问尊重系统减少动态效果偏好；关闭特效仍保留当前播放音符高亮。

## 未定稿

- 当前松绿色配色仅为试稿；用户认为配色尚不够好，不得标记为最终认可。
- 此目录中的曲谱与曲目为布局示例；静态档案没有连接真实数据。实际应用已连接乐谱库、音频与保存。
- 实际应用默认墨蓝与纸白，并提供松绿 / 夜间主题；配色仍可根据体验调整。
- 音色接入与测试边界见 [SOUNDFONTS.md](../SOUNDFONTS.md)。

## 原型可试操作

写谱 / 练习切换、选中音符、Z / C 或按钮调整音长、当前句 / 整首视觉播放、特效开关与搜索。
Z / C 仅在谱面获得焦点时生效。正式版的数字输入、快捷键配置与保存仍待实现。
