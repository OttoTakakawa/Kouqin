## 用户确定的交互

- 数字1–7表示音阶，不显示孔位；默认C，可选A；`[]`高音、`()`低音、`#`推键，双层同类括号支持倍音区。
- 数字大小提示相对音长。Z/C编辑时值，不采用按住计时。常用1/16、1/8、1/4、1/2、全音；四分音符为1拍。
- 默认Enter换句，可在按键设置改Tab；修饰键可自定义。
- 速度只有一个控件，预设与滑杆修改同一有效BPM，按曲保存；仍需点击保存/按Ctrl+S，不能把浏览器草稿当已落盘。
- 行号首次点选整句，再点同一行从句首起播；点击数字定位，双击数字直接播放。
- 「循环本行」在写谱和练习均可使用，循环时修改音长后继续播放；A/B端点与编辑选区独立。
- **空格键插入四分休止（duration:1）；有选区时在选区末尾追加，不覆盖原音符。** 这是已修复的数据丢失问题，不可恢复成通用替换选区路径。
- 新休止显示灰色「停」，可编辑时值；「不停」选项已移除。旧`type:space`仍不计时，显示「·」，选时值才转成休止；不要批量把旧分隔转成1拍。
- 原图不做右侧对照栏，原有收藏只读；左侧曲库和分类可折叠，音符特效可关闭。

重新启动当前曲库时，先确认4318没有已有服务，再在项目目录设置：

```powershell
$env:PORT="4318"
$env:HARMONICA_DATA="D:\Harmonica\data\rework-preview"

```

## 核心实现位置

- `public/app.mjs`：谱面编辑、选区、撤销/草稿、曲库、速度、简化工具栏、段尾处理和界面事件。
- `public/model.mjs`：验证、记谱解析/序列化、音高、标准时值、共用时间轴。
- `public/transport.mjs`：独立播放光标、当前句/A–B范围，以及编辑插入/删除后的端点跟随。
- `public/audio.mjs`：音频时钟调度、合成音、按音色缓存采样、暂停/循环/静音。
- `public/index.html` / `public/style.css`：界面结构和样式。
- `server.mjs`：本机接口、只读资料扫描、JSON写入队列和备份/回收；接口见`docs/API.md`。
- `scripts/build.mjs`：采样JS按纯文本打包，**不执行采样文件代码**；data URL使现有静态白名单服务无需重启即可加载新采样。
- `scripts/calibrate-harmonica-loops.py`：开发时从44100Hz单声道PCM计算循环点；日常播放不依赖Python。

时间轴公式：`(duration + tailHold) * (durationScale ?? 1) * 60 / bpm`。界面显示有效速度`bpm / durationScale`；旧谱载入不改快慢，手动调速后普通范围写入bpm并移除倍率。极端旧速度仍保留必要兼容倍率。**不要再额外乘第二个速度，也不要调速时改逐音duration。**

六种免费口琴采样为FluidR3、MusyngKite、GeneralUser GS、VCSL常规/柔和/颤音，另有合成音。各有独立循环表和增益；停止/切换时清除全部已加载乐器的残音。GeneralUser是FluidSynth离线渲染；VCSL是十孔口琴稀疏采样转调，不是全音区半音阶实录。来源、许可、派生方式见`THIRD_PARTY_NOTICES.md`与`docs/SOUNDFONTS.md`；音频输出检查不等于拟真度评价。

## 转谱现状与限制（个人数据不在Git）

- 用户允许转译自己提供的谱；转谱代理指定Luna Max或GPT-6.1-sol medium，不要擅自换高费用模型。
- 《卡农》主记录`canon-c-reworked-luna-max`，329音；原重复版本已归档，默认列表只保留一个入口。三个归档仍可恢复，不能删除用户编辑或新增一堆同名版本。
- 《花之舞》记录`flower-dance-luna-max`在4318，886音、53句，有倍低音，不能向旧4317保存接口直接写入。
- 最近Luna节奏校准：卡农56 BPM、花之舞100 BPM。卡农仅开头主题与参考谱对应，后续311音仍为估计；花之舞原图没有完整节奏符号，细分时值仍估计。不得对外宣称精确原曲还原，也不能所有曲目统一90 BPM。
- 段落中间的旧停顿已在4318按用户要求清理，保留边界停顿；不要导入旧中间结果而恢复它们。
- 原图、快照、校准报告、安全合并脚本保存在本机`work/`，包括`rhythm-calibration`、`canon-flower-rework`、`remove-internal-stops`、`consolidate-canon`，不在仓库。
- 对本机曲谱继续修订时要新读当前记录并备份，只修改已授权字段，保留用户后续编辑、速度、归档标记、边界停顿和音高顺序；不要拿旧候选JSON整份覆盖。
