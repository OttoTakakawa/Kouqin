# 播放与音长

## 常用入口与段尾处理

主编辑栏保留分数时值选择（1/16、1/8、1/4、1/2、全音）、增减、延长尾音、段后留白、撤销和换行按钮。更多时值与乐理名称放入「更多 → 精确设置」，A/B 入口收进「片段练习」，音色、音量与特效直接放在底部播放栏，唯一速度入口在播放栏。不要求用户掌握完整音符名称，常用时值仍有明确含义。

编辑区区分点击选中的符号与方向键定位的插入光标，避免点击「停」后退格误删前一个音符。点击后 Backspace / Delete 删除该符号；删除后光标留在删除处，后续退格向前删、Delete 向后删，撤销恢复选择状态。换行按钮与默认 Enter 使用同一插入逻辑，在光标处分句，保存与播放继续使用现有 break 数据。

剪贴板操作共用谱面选区，支持行号整行选择、鼠标拖选与 Shift+方向键。每行的「行尾」定位清除选区，便于将下一行整段粘贴到上一行末尾；选中上一整行再粘贴则替换该行。编辑栏提供复制、剪切与粘贴按钮，系统剪贴板同时携带纯数字谱与浏览器支持的自定义音符数据；同页文本回退保留最近复制内容的时值。剪切写入成功后才删除，异步粘贴须校验文档和选区没有改变；空内容或解析失败不修改原谱。

编辑模式的播放跟随以当前播放音符所在的整句居中，只滚动谱面容器。播放期间添加上下留白，使首句与末句也可居中；结束播放时扣回留白，保留所看内容的位置。滚轮、触摸、拖动滚动条及其他手动滚动会暂停跟随，选中下方音符不再改变起播位置；点击底栏「回到播放行」恢复居中跟随。「跟随播放」可主动关闭；练习模式维持已有滚动与点击跳转行为。

延长尾音写入选区末个有音高音符的可选 tailHold，保留基础 duration；取消只移除附加量。留白使用现有休止音符，插在选区末音与下一音 / 换行之间，重复设置会修改同一个停顿；谱面显示为灰色「停」。两者在同一 timeline 中参与播放、整体倍率和预计总时长，支持保存与撤销。若在原 B 端点后新增留白，循环终点随之扩到留白，确保循环中听得到停顿。

侧栏支持桌面整栏折叠与独立分类折叠，状态作为本机界面偏好保存；小屏继续使用覆盖式目录。搜索临时展开匹配分类，不覆盖用户的分类折叠偏好。

默认列表隐藏已存在可编辑谱的原始收藏入口，原图仍可通过「原有收藏」筛选访问。旧稿与补充片段可用 `archived: true` 收入「归档版本」，保留全部音符与用户编辑；打开后可「恢复此版本」。归档版本的 `primaryScoreId` 指向主入口，重开已归档的已保存草稿时优先打开主稿；未保存草稿仍原样恢复并继承归档标记，避免丢失编辑。

空格键直接插入四分休止（duration:1），选区存在时在其末尾追加，不调用覆盖选区路径；一次撤销恢复插入前的音符和选区。音长选择器只接受正时值，移除「不停」。旧谱分组空格保持不计时，显示为灰色「·」，选中可设置时值转为休止，避免改写整库节奏。混选时批量时值只调整音符与已有休止。原有收藏继续按来源路径/同名标记已有可编辑谱。

音符字号在四分音符以下每个二倍时值档差 5px，以上差 10px，再限制在 18–58px；1/16 和 1/8 分别为 23px 与 28px（100%缩放），不再同时被最小字号压平。休止仍使用固定的小号灰字。

为保留《花之舞》等文字谱的倍低音，音区扩展到 -2 至 2。同类双层括号表示倍低 / 倍高音；分组结束后恢复外层音区，混合高低音括号仍报错。JSON 校验、文字导入导出、显示和播放共用这一音区范围，既有单层谱保持原义；无需更换音色或改动音长。

播放速度合并为一个有效 BPM 控制，提供舒缓60、适中90、轻快120、快速160预设和连续滑杆。用户不必同时调整 BPM 与倍率。旧谱读取使用 bpm / durationScale，保持原来实际速度；首次调速把普通范围速度写回 bpm、移除倍率，极端旧速度以必要倍率兼容。逐音 duration、tailHold 与字号不变；保存、撤销与重读保持一致。

行号首次点击选整句并定位，已选整句再次点击直接从句首播放。播放栏直接显示「循环本行」，编辑和练习两种模式共用，点击启用会从当前句首起播；关闭停止循环。逐音或批量编辑会重建循环播放时间轴，继续播放且保留编辑选区，不进入下一句。A/B片段仍可在片段练习菜单单独设置。

## 免费口琴音色切换

新增免费MusyngKite音色，现有FluidR3和合成音保留。按音色分别缓存采样与加载任务、共用主音量；切换/停止清除所有乐器残音。新采样和专用循环表随本地前端打包，采样文本只解析数据、不执行，避免依赖服务重启或外网。许可、来源与循环重建说明见SOUNDFONTS.md及THIRD_PARTY_NOTICES.md。


其余免费音色接入GeneralUser GS和VCSL常规/柔和/颤音，均独立缓存在同一播放器并使用各自循环表与增益。GeneralUser经FluidSynth离线渲染口琴预设；VCSL以原始稀疏采样为锚点，由播放器转调覆盖数字谱音高。采样只解析为数据，不执行代码，也不依赖外网或本地服务重启。归属与许可见第三方说明。

## 当前本地数据归属

每首谱的bpm/兼容倍率保存在本首JSON中，速度修改属于可撤销编辑，点击保存后落盘，切歌与重开取各自谱内速度；音色/音量/主题等全局界面偏好另存在浏览器localStorage，未保存草稿也在浏览器。F盘Markdown与引用图片只读。当前4318服务已与data/rework-preview的59份JSON逐记录对照确认；4317仍使用data根目录，二者不自动同步。后端每次覆盖前保留同名.json.bak一份，删除转入该数据目录的trash；这些不是完整版本历史或跨盘自动备份。data已在Git忽略列表，不随代码上传。
